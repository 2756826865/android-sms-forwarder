# 短信转发器 1.2.3(101702)

版本代码：1205，可覆盖安装 1.2.3 和 1.2.3(101701)。

## 修复

- 修复旧版升级后关闭邮箱通道，后台仍可能通过旧 SMTP 配置继续推送的问题。
- 修复删除邮箱通道后，重新进入应用又被旧配置自动导入的问题。
- 修复修改导入通道账号后，旧账号配置可能再次生成实例的问题。
- 通道迁移到实例管理后，以实例的启用、停用及删除状态为准；发送任务执行时也拦截旧配置回退，避免仅修改界面而后台继续发送。
- 同一迁移规则覆盖其他旧版普通转发通道；保留其他显式启用实例，支持只保留 PushPlus。
- 修复实例删除未保存成功时仍返回删除成功的问题。

## 验证与说明

- 本地12项通道仓库宿主测试通过，覆盖首次迁移、关闭、删除、配置重新加载、账号修改、多个邮箱实例及保留 PushPlus。
- 宿主测试对无关 Android 依赖使用桩，不等同于真机测试；正式APK以GitHub Actions完整测试、签名构建及校验为准。
- 升级后请再次关闭或删除不需要的邮箱通道；此前已重新导入且仍开启的实例不会被擅自关闭。
- 已经提交到邮件服务器的历史消息无法撤回；本次修复阻止后续旧配置发送。
- 包含 1.2.3(101701) 的查询与后台刷新优化、钉钉和企业微信重连修复；KSU模块未修改。
