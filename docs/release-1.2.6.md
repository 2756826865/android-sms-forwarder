# 短信转发器 1.2.6

版本代码：1215 · 2026-10-24

- **双卡识别与国内 ROM 深度适配**：支持识别高通/联发科/紫光展锐等国内定制 ROM 的广播卡槽参数，解决自定义卡名称不生效、双卡规则漏发及指纹不一致引发的重复转发问题。
- **后台保活机制重构**：解除前台保活服务对“系统默认短信应用”的硬编码绑定，确保在非默认短信应用（副手/转发模式）下，开启保活通知后进程持续稳定常驻，短信到达时不被主动终止。
- **规则模板引擎增强**：规则模板全面支持小写变量（`{{from}}`, `{{body}}`, `{{code}}`, `{{time}}`, `{{sim}}` 等）及直观中文占位符（`{{发件人}}`, `{{短信内容}}`, `{{验证码}}`, `{{时间}}`, `{{卡槽}}`, `{{卡槽序号}}`, `{{接收号码}}` 等）。
- **验证码防误判与签名剔除**：重构验证码提取逻辑，自动剥离首尾发件方签名（如 `【10086】`、`【12306】`），过滤常见客服电话和年份，杜绝银行卡尾号被误识别为验证码。
- **黄页与企业 Logo 智能匹配**：内置 569+ 特服号与银行政企黄页数据库，会话列表、搜索页及系统通知栏自动显示官方品牌名称与高清圆形 Logo，未读消息徽章精准联动。
- **历史漏发补偿与心跳报活优化**：修复 `SmsRecoveryWorker` 扫描历史短信时的卡槽反查兜底，优化 `HeartbeatWorker` 设备状态报活的空安全与容错。

支持同签名旧版覆盖升级，无需清除数据。已通过全量自动化回归与签名构建验证。
