# 短信转发器 1.2.3(101703)

版本代码：1206。

状态：测试构建完成，尚未正式发布。

## 后台与耗电优化

- 未保存过保活设置时默认按需运行，收到短信后启动短时处理，完成后结束；已有明确开关选择继续保留。
- 常驻服务入口更名为“兼容保活模式”，供锁屏后出现漏收的设备按需开启。
- 短信保活服务被系统重建时，重新核对开关和默认短信身份，不符合条件就停止。
- 服务交接或短信处理异常时增加最小处理和补偿任务。
- 补偿扫描按需读取本地短信 ID 与转发记录，减少无消息时的数据加载。
- 模板按实际使用的变量读取联系人、SIM、电量及网络信息，减少不必要查询。
- 六类远程服务减少重复发布前台通知，文案区分监听服务运行和网络连接状态。
- 网络远程来源继续由各自开关管理，短信指令不使用网络长连接。

## 转发执行与记录

- 转发记录改用独立数据库存储，支持历史数据迁移、分页查询和事件触发刷新。
- 转发记录支持“仅重试此通道”，使用保存的实际投递数据，不重新匹配全部规则。
- 通道组支持并行发送、成功即停、失败即停，仅作为显式规则目标，不额外加入默认广播目标。
- 增加组执行状态保护；结果不明确时标记“结果未知”，避免直接自动重发或切换备用通道。
- Webhook 增加 HTTP 状态、响应文本包含、JSON 字段值三种成功判断方式；原有配置默认保留 HTTP 判断。

## 更新与入口

- 新增手动检查更新，仅在点击时检查，不启动自动更新弹窗。
- 安装包下载校验大小和 SHA-256，并核对包名、版本及签名后交给系统安装。
- QQ 群入口支持复制群号并打开入群链接。
