# 短信转发器 1.2.3(101701)

版本代码：1204。可覆盖安装原正式版 1.2.3。本次集中优化短信列表查询和后台刷新，修复长连接连续失败时重连过密的问题。

## 优化与修复

- **减少短信和联系人重复读取**：单会话查询只统计该会话未读数；刷新列表时复用已获取的会话资料，避免每个会话再次查询联系人和未读信息。
- **减少本地历史遍历**：补齐缺失会话时仅查询必要的最新短信；只有按会话查询为空时才尝试按号码兜底。
- **后台界面刷新合并**：经典版和开发版首页退到后台后，界面刷新事件先合并，回到前台再刷新；短信接收、转发及补偿同步继续工作。
- **长连接重连修复**：钉钉 Stream 和企业微信智能机器人连续断连时，按5、10、20、40、60秒逐步延长重连等待；连接稳定满60秒后恢复快速重连，避免异步失败时总以5秒频繁重试。
- 保留现有心跳频率、短信发送和选卡策略；KSU模块未修改。

## 验证与说明

- 本地32项宿主测试通过，覆盖数据库查询、重连策略、刷新合并和相关长连接/白名单逻辑；部分宿主编译使用Android依赖桩，不等同于完整APK验证。
- 正式APK以本次GitHub Actions签名构建与校验结果为准。
- 尚未进行真机待机耗电对比，不能承诺具体省电幅度或认定所有耗电问题均已解决。
- 连续失败进入最长等待后，网络恢复可能等待剩余重连间隔，最多约60秒，再加连接握手时间。
