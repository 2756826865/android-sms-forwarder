# 短信转发器 1.2.4

版本代码：1207

## 按需运行与后台优化

- 未设置过保活选项时默认按需运行：短信到达后启动短时处理，完成后结束；已有明确保存的保活选择继续保留。
- 将常驻服务入口改称“兼容保活模式”；系统恢复该服务时重新核对开关和默认短信身份，不符合条件就停止。
- 短信服务交接或处理异常时增加最小处理和补偿任务，保留断网等待、退避重试及低频漏收补偿。
- 减少无消息时加载短信 ID、转发记录，以及模板未使用变量时的联系人、SIM、电量和网络查询。
- 减少远程服务重复通知刷新，明确区分监听服务运行与网络连接状态；短信远程指令仍按事件触发，无需网络长连接。

## 转发执行与记录

- 转发记录改为独立数据库存储，迁移旧记录，支持分页查询和事件刷新，减少整批读写及固定间隔刷新。
- 支持“仅重试此通道”，使用保存的实际投递数据，不重新执行整套规则；旧日志缺少完整数据时不使用截断正文重发。
- 通道组支持并行发送、成功即停、失败即停；仅作为明确选择的规则目标，不额外加入默认广播目标。
- 保存通道组执行状态；发送超时等结果不明确的情况标记“结果未知”，避免自动重发或自动切换通道造成重复。
- Webhook 增加 HTTP 状态、响应文本包含、JSON 字段值成功校验；原有配置默认保留 HTTP 判断。

## 更新、入口与声明

- 新增手动检查更新，仅点击时检查，不自动弹出更新提示。
- 下载校验安装包大小与 SHA-256，并核对包名、版本及签名后交给系统安装。
- 点击 QQ 群入口复制群号并打开入群链接。
- 完善首次使用声明，补充隐私、第三方服务与防诈说明。
- “关于”新增“特别声明”入口，方便随时查看；经典界面和开发版共用该页面。

## 延续修复

- 包含 1.2.3(101702) 的旧邮箱配置重复推送、删除后重新导入及修改账号后旧实例恢复等修复。
- 保留已有后台刷新节流及钉钉、企业微信重连退避优化。
