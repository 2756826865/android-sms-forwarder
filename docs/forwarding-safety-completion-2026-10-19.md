# 转发安全边界补齐（构建候选）

基线 `e0531e078935e3e2215608e263bb4d197a1a839f`，工作分支 `fix/forwarding-safety-completion`。整合收费短信保护、队列诊断/补偿与会话地址解析修复；原工作分支保留，OkHttp 升级不合入本次构建。

## 通俗更新说明

- 补齐短信降级路径的防重复保护，旧的无法确认身份的降级任务不再自动发送收费短信。
- 系统保留旧任务时，保留原任务的数据，避免重复入队把恢复信息覆盖。
- 手动重试前先核对原任务，仍在排队或执行、查不到或查失败时不重发；连续点击只安排一次。
- 保留具体失败原因，排队状态单独记录；原通道变更时停止重试，不改投其他目标。

## 验证和限制

58 项 JVM 检查（含实际 WorkData 序列化）、30 项真实 SQLite 检查，以及 35 项发送/重试入口、14 项调度器、11 项存储方法的宿主替身场景通过，共 148 项。详细环境和替身范围见队列与收费短信说明；没有发送真实短信，没有访问真实转发服务。

WorkManager API 相关目标代码已编译核对，但未完成完整 APK 编译和真机验证，不能据此承诺已解决用户设备的移动数据排队或本次扣费根因。

收费提交与重试预约采用保守防重：认领后进程中断可能不再自动补发；清除应用数据会清除本地去重证据。此补丁不能撤回已提交给系统/运营商的短信，不能减少长短信分段计费，也不是任意多设备转发环路检测。

此文的验证记录截止本地检查完成时；后续准备构建 `1.2.4(101901)` / `1210`。构建和发布状态以 GitHub Actions / Release 为准，不覆盖旧版本安装包，KSU 未修改。

本次整合另通过 12 项地址解析策略检查与 6 个实际读取函数的 Provider 替身场景，共计 166 项针对性检查。
