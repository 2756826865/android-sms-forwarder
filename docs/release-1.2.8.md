# 短信转发器 1.2.8

发布日期：2026 年 11 月 2 日 · 版本代码：1218

本版重点完善短信接收、即时显示、转发恢复和后台通知管理。

## 主要更新

- **常驻通知默认合并为一条**：短信守护与企业微信、飞书、钉钉、Telegram、WebSocket、邮箱来源共用一个前台服务，汇总实际就绪数及来源状态。关闭一个功能不影响其余来源，全部关闭后退出；升级时清理旧服务通知。
- **短信接收更可靠**：增加加密暂存、持久化接收记录和异常恢复；系统写入结果不确定时先核对，避免盲目重复插入。配置异常不会直接阻断短信保存。
- **信息页面更及时**：快速提交本地短信与会话，两套主页订阅 Room 变化；联系人资料后台补全，历史导入分页处理，转发不等待页面绘制。
- **补同步更准确**：按目标消息 ID 严格核验，补齐最新 50 条窗口之外的短信；恢复扫描去重并确认本地结果后推进检查点。
- **转发与双卡保护**：优先采用真实接收卡证据，无法确认时保留未知；重试保留原始目标、SIM 快照和任务所有权。相同凭据重新加密不再被误判为更换配置。
- **通知与已读状态修补**：完善通知补偿、异步发布顺序和待同步通知撤销；后台会话刷新不主动误标已读，过滤短信不应压掉正常通知。
- **灵动岛通知保留**：小米、OPPO 和通用 Live Update 适配不再让整条短信通知随展示超时消失。
- **验证码弹窗可控制**：经典版与开发版设置共用弹窗开关，显示前再次核对；关闭不影响后台短信通知和转发。
- **后台资源与诊断优化**：修复唤醒锁释放，减少重复同步和恢复任务竞争，完善网络重连唤醒；区分服务请求启动、实际前台化及启动失败，并补发权限恢复后的后台状态通知。

普通新短信、发送失败和短时短信处理通知保持独立；本版合并的是后台服务常驻通知。
