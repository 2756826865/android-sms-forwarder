# 短信转发器 1.2.7

版本代码：1217。

- 开发版支持 Miuix / Material 风格切换，分类设置、主题配色、迷你大盘预览及悬浮导航。默认橘红，Monet 默认关闭；保留已保存的主题设置。
- 大盘整合收件、成功、队列、失败四列统计，保留运行状态及最近记录详情；通道受理不代表终端送达。
- 历史短信按1000条批量写入，每500条更新进度，增加按ID续查和同步诊断；会话时间合并避免旧时间覆盖新时间。
- 更新黄页数据及号码展示，增加私人号码匹配保护。
- 电量提醒增加测试发送；发送日志支持预览、保存、分享，并纳入保留的持久化发送与转发记录。
- 改善设置二级页、日志弹层的底部适配，以及弹窗文字、深浅主题和圆角；教程在开发版设置内打开。
- 新建短信加号固定为1.2.6绿色；调整短代码回复入口及会话已读处理。

## 验证范围

分支构建成功不等于真机验收通过。增加全量同步空游标与异常记录失败保护；读取状态以系统数据为准，标记已读不改变会话时间。不同 ROM 下的全量同步完整性仍需真机核验，不宣称覆盖所有设备。完整变更和验证限制见 [CHANGELOG](../CHANGELOG.md)。
