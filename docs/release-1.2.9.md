# 短信转发器 1.2.9

发布日期：2026 年 11 月 10 日 · 版本代码：1219

本版重点加强短信直发防无限循环与频率保护，新增系统短信通知监听防夺权兜底模式、Bark 通道 iOS 专注模式突破与验证码自动复制、规则单通道独立模板与内容清洗，修复双卡自定义名称识别与验证码无障碍自动填充，并全面对齐经典版与开发版（Miuix / Material）功能与设置项。

## 主要更新

- **短信直发防无限循环与频率限制**：
  - 新增本机双卡号码识别（`isSelfNumber`），拦截本机卡槽互发与自收自转。
  - 新增已转发短信模板特征识别（`isForwardedLoopContent`），防止多设备或多级短信直发形成无限循环扣费。
  - 新增 **短信直发发送频率限制开关**，支持自定义 **1 分钟上限（默认 10 条）** 与 **1 小时上限（默认 30 条）**，基于持久化账本硬拦截超额发送。
  - 所有短信直发实例及全局配置均支持开启 **「仅断网时发送（断网直发兜底）」**。
- **系统短信通知监听兜底（vivo / OPPO / 魅族防夺权模式）**：
  - 内置 vivo/iQOO、OPPO/ColorOS、华为、荣耀、小米/魅族、三星及 Google 信息等主流品牌系统短信包名，支持一键加入通知监听白名单。
  - 新增 **「默认短信正常时跳过系统短信通知」** 智能防重开关：正常持有默认短信权限时自动忽略系统短信通知防重复推送；一旦被系统自动夺回默认短信权限，立即通过通知栏无缝兜底转发。
- **Bark 通道增强（iOS 专注模式突破与验证码自动复制）**：
  - 新增通知提醒级别 `level` 配置（`默认提醒 active` / `时效性突破专注 timeSensitive` / `重要警告忽略静音 critical` / `静默 passive`）。
  - 新增自定义通知分组 `group` 与 **「收到验证码时在 iPhone 自动复制」**（自动提取验证码并附加 `autoCopy=1&copy=验证码`）。
- **规则单动作独立模板与内容清洗增强**：
  - 开发版规则编辑器支持为每个目标通道实例单独设置专属模板（如 Webhook 发送完整结构、短信直发仅发简短摘要）。
  - 经典版规则页同步开放「独立消息模板」与「正则替换内容清洗（`pattern => replacement`）」。
- **鸿蒙 NEXT（卓易通容器）兼容提示与批量发送间隔扩展**：
  - 自动检测鸿蒙及卓易通容器环境，提供宿主多任务与跨容器剪贴板粘贴指引。
  - 批量发送支持立即发送及 1、2、3、5、10、15、30、60 秒多档发送间隔选择。
- **双卡自定义名称与验证码无障碍自动填充修复**：
  - 兼容更多 ROM 的 `subId`、`simSlot`、`slotIdx` 广播参数，修复双卡同时设置自定义名称时推送不显示自定义卡槽名称的问题。
  - 在 `AndroidManifest.xml` 中正式注册 `SmsAutofillAccessibilityService` 无障碍服务，接通焦点输入框自动填入与填充后自动点击提交开关（`autoSubmit`）。
- **隐藏功能补齐与跨版本兼容修复**：
  - 在「转发高级设置」中补齐 **转发内容隐私脱敏（手机号中间 4 位与验证码遮挡）** 及 **双卡本机号码** 配置。
  - 在「远程发送」页面接入 **系统发信环境检查卡片**，并补齐 Telegram 远控的 **自定义反代 API 地址（`customHost`）**。
  - 在开发版「规则管理」补齐 **规则作用范围（`scope`）** 与 **最近规则判定** 展示；修复经典版保存规则时覆盖清空开发版 v2 高级规则字段的问题。
  - 对齐开发版 **Miuix / Material** 主题页（补齐橘红主题色、AMOLED 纯黑背景开关，修复非壁纸动态色下调色板风格与 2021/2025 色彩规范联动）。
