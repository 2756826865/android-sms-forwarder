# 短信转发器 1.3.1

发布日期：2026 年 11 月 18 日 · 版本代码：1301

本版本为全量代码深度复盘与稳定性加固版本：围绕「0ms 秒发送、高频连发 1:1 守恒、零误扣费运营商短信、Android 12-16 前台服务防崩溃、经典版与开发版双向完整对齐」进行了三轮全模块排查修复。

## 主要更新

- **高频轰炸 / 连发短信 1:1 守恒与防漏发**：
  - 将广播与系统短信通知的跨路径防重升级为**一对一配对令牌制**，既消除双广播（`SMS_DELIVER` + `SMS_RECEIVED`）与通知的重复推送，又保证数秒内连发相同验证码或批量轰炸短信时逐条守恒不吞消息。
  - 当系统短信通知因发件人为联系名称（缺少真实号码）或规则 `0` 命中而未实际转发时，立即回滚释放通知令牌且不写已转发证明，交由随后到达的广播或补偿扫描凭真实号码与物理 SIM 卡槽精准转发。
  - 补偿扫描（`SmsRecoveryWorker`）排除系统内部跳过记录并结合入站快照还原真实接收卡槽。
- **零误扣费与运营商计费闭环防护**：
  - **短信直发（`SMS_DIRECT`）严格隔离**：第三方应用通知默认不触发付费短信直发；已显式绑定到转发规则的 `SMS_DIRECT` 实例严守规则命中边界，绝不在未命中的普通/垃圾短信上误发；多收件人同源直发互不误拦，同时精准拦截本机回环。
  - **远程短信指令跨路径去重**：新增 15 秒跨路径内容指纹去重，杜绝通知兜底与广播同时到达导致执行两次发信指令。
  - **群发短信断点续发**：收件人批次改为本地文件持久化（规避 WorkManager 10KB 限制），逐条发送前记录进度检查点，进程被系统回收重试时绝不重复向已发号码扣费发送。
- **Android 12-16 稳定性、数据库自愈与安全隐私**：
  - 修复双广播与停止保活场景下 `IncomingSmsService`、`SmsKeepAliveService`、`PushPlusWorker` 的 `ForegroundServiceDidNotStartInTimeException` 崩溃隐患。
  - 入站账本数据库（`SmsIngressDatabase` v8）新增列自检自愈，消除旧版本跨代覆盖升级时的 `SQLiteException`。
  - 修复内存环形日志 `clear()` 后容量归零的缺陷，补全 `+86` 手机号、URL Token 与动态码脱敏；全局接入崩溃诊断脱敏记录，并在系统云备份规则中排除全部敏感凭据与设备绑定密文。
- **全转发协议栈、规则引擎与双 UI 完整对齐**：
  - 区分提交前网络/TLS/OAuth 预取异常（`PreSubmitNetworkFailure`）与提交后未知异常，使 SMTP 握手认证阶段、企微/飞书/测试号预取 Token 失败可安全自动重试；修复 QQ（OneBot/Qmsg）实例字段、自定义 Webhook `GET` 请求与 URL 变量渲染、`ntfy` 非 ASCII 标签清洗、`WxPusher` 多订阅者判定及跨午夜免打扰星期归属。
  - 保留经典版规则发件人匹配与多关键词 `OR` + 正则 `AND` 语义；修复模板渲染二次展开注入与年份数字被当成验证码误脱敏的问题。
  - 全面打通经典版与 Compose 开发版在转发通道（含旧版 PushPlus 自动迁移）、远控来源、规则管理、配置导入导出上的双向实时同步，并将黄页词典初始化移出列表绑定主线程，滑动更丝滑。

完整累计变更见 [CHANGELOG](https://github.com/2756826865/android-sms-forwarder/blob/v1.3.1/CHANGELOG.md)。
